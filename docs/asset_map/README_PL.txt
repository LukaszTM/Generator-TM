TestPilot Studio - pakiet assetów UI (każdy element osobno)

Zawartość:
- assets/buttons/      -> osobne pliki PNG z przyciskami
- assets/tabs/         -> osobne pliki PNG z zakładkami i elementami nawigacji
- assets/icons/        -> osobne pliki PNG z ikonami
- assets/window_style/ -> osobne pliki PNG z elementami stylu okna i komponentami UI
- fonts/               -> czcionka Inter z obsługą polskich znaków
- docs/                -> pliki CSV z mapą wyciętych assetów

Pakiet przygotowany na podstawie wcześniej wygenerowanej wizualizacji TestPilot Studio.
Arkusze zostały automatycznie rozcięte na osobne pliki PNG na podstawie przezroczystości.
Jeśli chcesz, mogę w kolejnym kroku przygotować też wersję bardziej ręcznie uporządkowaną
(np. z nazwami typu button_primary_normal, tab_active, icon_home itp.).
